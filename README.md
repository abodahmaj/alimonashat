# حاسبة توزيع حصص النشاط الطلابي (10%)

أداة ويب بسيطة لحساب وتوزيع حصص «النشاط الطلابي» بنسبة 10% من الخطة الدراسية،
حسب دليل «مجالات وبرامج النشاط الطلابي والفترات اللاصفية للعام 1448هـ».

## الميزات
- حساب عدد حصص النشاط وفق نسبة 10% من مجموع الحصص الأسبوعية.
- دعم المراحل: ابتدائي / متوسط / ثانوي، مع الصفوف العليا والفترات اللاصفية.
- استثناء أكثر من مادة من الحساب.
- جدول أسبوعي + تقرير جاهز للطباعة (PDF عبر طباعة المتصفح).

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو زر النسخة المنشورة:
https://abodahmaj.github.io/alimonashat/
